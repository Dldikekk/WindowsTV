# WindowsTV Launcher

Веб-лаунчер в визуальном стиле Windows 10, созданный на HTML, CSS и JavaScript без сборки и зависимостей.

## Запуск
Откройте `index.html` в современном браузере. Для более надёжной работы можно запустить локальный сервер: `python -m http.server 8000`, затем перейти на `http://localhost:8000`.

## Возможности
- Фон в стиле Windows, полупрозрачная верхняя панель и нижняя панель задач.
- Закреплённые сайты, поиск, быстрые ссылки и добавление/удаление сайтов.
- Встроенный просмотр страниц через iframe.
- Настройка акцентного цвета и прозрачности.
- Демонстрационный PIN-код для блокировки интерфейса.

## Важно
PIN хранится в localStorage как обычный текст и не является надёжной защитой. Не используйте настоящий пароль. Многие сайты запрещают загрузку в iframe через CSP или X-Frame-Options; для них используйте открытие в отдельном браузере. Это веб-демо, а не полноценная операционная система.
